# maxuexin.github.io
My personal homepage & navigation portal

## Pages
- `index.html` — 门户首页
- `html/idcard.html` — 个人名片
- `html/kuaijiejian.html` — 我的快捷键（键帽视图）
- `html/kuaijiejiandaquan.html` — 快捷键大全（列表视图）
- `html/yinyue.html` — 音乐收藏（按歌手分类，数据在 `js/music-data.js`）
- `html/shuji.html` — 书籍收藏（平铺书单，数据在 `js/shuji-data.js`）
- `html/dianying.html` — 电影收藏（按类型分类，数据在 `js/dianying-data.js`）
- `html/ruanjian.html` — 软件插件收藏（平铺清单，数据在 `js/ruanjian-data.js`）
- `html/wangzhan.html` — 网站收藏（分类导航，数据在 `js/wangzhan-data.js`）
- `html/xuexi.html` — 学习文件（网盘入口，链接在 `js/xuexi-data.js`）

以上收藏类页面右上角均有「网盘」快捷按钮（共用 `js/drive-btn.js`）。
